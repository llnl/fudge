Downloading¶

The latest version of Fudge and GNDS is available from https://github.com/LLNL/fudge. Users with LLNL gitlab accounts can also access FUDGE at https://lc.llnl.gov/gitlab/nuclear/fudge.

Please let us know if you have any difficulty accessing the code!
